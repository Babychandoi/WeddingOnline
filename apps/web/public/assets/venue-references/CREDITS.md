# Venue reference photographs

Each venue preview links to its original photograph and identifies the photographer and license. The same credits are recorded by venue ID in [`catalogPhotoReferences.json`](../../../src/components/three/catalogPhotoReferences.json).

The local WebP photographs are resized and recompressed. Each `.depth.webp` is a relative depth estimate derived from its corresponding photograph with Depth Anything V2 Small. The local photograph and its depth map are shared under the license recorded for that photograph.
